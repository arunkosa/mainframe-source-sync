# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public issues.

Until a dedicated security contact is established, report security concerns privately to the current maintainers through the repository hosting platform's private contact mechanism, or through whatever private reporting channel is listed in the repository profile.

Include:

- a description of the issue
- affected files or components
- reproduction steps if available
- potential impact
- any suggested mitigation

## Response expectations

The project aims to acknowledge reports promptly, reproduce the issue, and prepare a fix or mitigation before public disclosure.
