# Sample JCL

The files in this directory are sample z/OS adapter assets for `mainframe-source-sync`.

They are intentionally not part of the core sync engine. Treat them as examples that you should adapt to your own job card standards, `BPXBATCH` setup, routing rules, and downstream processing requirements.

See [../adapters/zos/README.md](../adapters/zos/README.md) for the adapter boundary and responsibilities.
